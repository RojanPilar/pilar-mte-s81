# RJN Automotive — Luxury E-Commerce Visual Platform

A premium, high-end automotive e-commerce landing platform engineered natively to showcase luxury hypercar design structures, typography grids, and conversion-focused visual layout consistency.

## Tech Stack
* **UI Grid Framework:** Bootstrap 5.3.3
* **Core Languages:** Vanilla JavaScript, HTML5, CSS3
* **Content Delivery Networks (CDNs):** jsDelivr, Unpkg
* **Deployment Platform:** GitHub Pages

## Key Features Built
* **High-Fidelity Visual Matrix:** Custom product presentation rows detailing precise vehicle specifications, badge overlays, and local currency formatting controls (`₱38,500,000`).
* **Media & Article Slider:** Touch-responsive, touch-friendly fluid carousel grids built to render luxury resources cleanly.
* **Mobileview Optimizations:** 100% viewport fluid constraints across sticky header navigations, active call-to-actions, and structured footers.
* **Performance Engineering:** Light, dependency-free vanilla coding optimized with asset caching layers to minimize initial page load lag.

## Installation & Local Setup
1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd s81-mte
   ```
2. **Launch via local environment:**
   Simply open `index.html` in any modern web browser or run using a text editor Live Server extension.
